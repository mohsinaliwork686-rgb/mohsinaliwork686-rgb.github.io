Open source

  • promptlint

    A linter for LLM prompt templates.

    • Finds the bugs that only show up in production: a JSON example that breaks .format(), a variable the code never passes, an API key left in a prompt, user input pasted straight into instructions.
    • Reads Python, YAML and Markdown, reports the exact line and column, and has an autofix that checks the text is still where it expects before changing anything.
    • No runtime dependencies. Tested on Linux, macOS and Windows across three Python versions.
    Python · static analysis
  • ragsweep

    Measures which retrieval settings actually find the right passage.

    • Sweeps chunk size, overlap, embedding models and BM25 keyword search against a labelled question set, and ranks every combination.
    • On its example corpus, keyword search matched embeddings on four of five question types. Embeddings only pulled ahead when a question's wording did not match the document.
    • Shares work across the sweep, so 54 runs take 1m 41s the first time and 1.3s after that.
    Python · embeddings · evaluation
  • contextlab

    Plans a context window before it overflows.

    • Shows what fits in a model's window, what each part of the request costs, and exactly where an over-long request gets cut.
    • Runs entirely in the browser. Token counts that are estimates are labelled as estimates, never passed off as exact.
    • Any setup can be shared as a compressed link.
    TypeScript · Next.js Try it live →
  • llm-router

    One endpoint for many language models, with a spending cap that holds under concurrent load.

    • Speaks the OpenAI API, so an app adopts it by changing its base URL. Routes each request by policy and falls back when a provider fails: retries what can recover, skips a revoked key, and stops on a request every model would refuse.
    • Reserves each call's worst-case cost before it starts, in one atomic step in Redis, so several routers share one cap. In the demo, ten simultaneous $0.30 requests against a $1 cap: three answered, seven refused before reaching a model.
    • 236 tests, including a deliberately racy store that the concurrency test is shown to catch. CI on Python 3.11 to 3.14 with a real Redis, on macOS and Windows, and the Docker demo itself.
    Python · FastAPI · Redis See the demo →
  • helmdrift

    Shows what was changed by hand in a Kubernetes cluster, compared with its Helm chart, and who changed it.

    • Filters out the noise that makes a raw diff useless: bookkeeping, values the API server filled in, and values written another way, such as 0.5 CPU and 500m.
    • Names the tool behind each change (kubectl-edit, kubectl-set, kubectl scale), read from the cluster's own record of who set each field. With Helm 4, those are the fields that block the next upgrade.
    • Tested on objects captured from a real cluster before and after drift. CI runs an end-to-end check on a real kind cluster, and the tests on Linux, macOS and Windows.
    Python · Kubernetes · Helm See it run →

Contributions

  • redis-py

    Documented the connection pool limit and BlockingConnectionPool in redis-py, the Python client for Redis. Merged.

    • Found while building llm-router: since redis-py 8.0 a pool holds 100 connections and fails at once when they are all busy, and the docs did not say so.
    • Opened the issue, agreed the scope with a maintainer, and went through two rounds of review: no new warnings in the docs build, and a broken example in the existing docs fixed along the way.
